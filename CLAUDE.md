# bergknapp-website

Static one-page site for Bergknapp Softworks at https://bergknapp.works, hosted on Netlify (project `bergknapp-works`) and deployed from `main` of `beaugunderson/bergknapp-website`. `netlify.toml` publishes the repo root; no build.

- Keep the page a directory: one card per released app or CLI tool pointing at its own site (knap.rocks, spacebar.tools, tuck.bar) or GitHub repo (Tracer, Obliscence). Galdra and Narrowcast have explicitly requested coming-soon cards; keep those non-interactive until there's a real destination or signup flow. Product detail lives on the app sites or READMEs, not here. Use Tracer’s README screenshot; keep Obliscence screenshot-free and explicitly say it works with both Claude Code and pi. Every card has a logomark; Tracer and Obliscence’s reusable originals are `assets/tracer-icon.svg` and `assets/obliscence-icon.svg`. Product marks have their own identities, not the Bergknapp spruce palette: Tracer uses its app’s cyan/yellow/red chart colors; Obliscence uses ink blue and lilac.
- Keep the layout compact: use subtle spruce backgrounds to group each app, without border outlines, horizontal dividers, or oversized empty image/text panels. Prefer informative app UI captures; Galdra should show session choices and descriptions, not just the abstract room. Keep every card half-width on desktop in independent columns, with consistent gaps instead of shared rows that trap whitespace; stack on phones. Keep Tracer’s screenshot cropped by 2px at the top to remove the stray colored edge, and omit visible image captions (identify illustrative demos in alt text instead).
- Copy stays short and in Beau's voice. Add a card when software is ready to distribute, even if its destination is a GitHub repo rather than a dedicated site; drop the card when it goes away. Keep the headline restrained and sans-serif throughout; no contrasting italic-serif or accent-colored second line.
- Use a dark spruce background even in light OS mode. No top navigation (including About), "The apps" heading/tagline, logo caption, location/byline, personal GitHub, or "Say hello" links. Product GitHub links are fine. Keep the name explanation without a heading or pronunciation. Give the hero text enough width to stay on single lines on desktop; allow natural wrapping on smaller screens. Beau's name appears once in the visible page, linked to his personal website in the footer; don't display the domain as a separate link.
- The mark is a top-down stonecrop (sedum) rosette, no rock, in the Blue spruce palette. Each leaf ring has a distinct brightness range. `index.html` owns the `<symbol id="rosette">` and light/dark CSS colors; run `python3 scripts/sync-logo.py` to update `favicon.svg` and the mark in `og.html`, then regenerate PNGs per the README. Keep the approved geometry unless Beau asks to change it.
- DNS is at Spaceship, not Netlify: `@ A 75.2.60.5`, `www CNAME bergknapp-works.netlify.app`, TTL 300. Manage records through the Spaceship API (`spaceship API key` in the emmylou 1Password vault); never move nameservers to Netlify (DNSSEC DS at Spaceship makes that SERVFAIL, see tuck's CLAUDE.md).
- Each dedicated app site links back here in its footer; when adding an app with its own site, add the reciprocal link there.
